# 运动男子健体修图 Skill

版本 1.3.0，规则版。已完成静态检查，实际出图质量待实测。

默认目标为健身网红感。完整健体修图应在原有身体基础上，产生可感知的肌肉视觉表现力提升，让胸肩背臂更有肌肉感、体积感、立体感和健体气质。增强不限于增大围度，幅度按本图基础、收益和工具能力动态分配，不使用固定百分比机械放大。保持自然也须体现正向改善。

本文件控制执行；[肌肉审美与形体调整规则](运动男子健体修图参考/肌肉审美与形体调整规则.md)集中定义审美、五维判断、肌群方向、联动及形体错误。按需读取并复用已读内容，不向图像工具输入整篇解剖理论。

## 阶段 A：识别任务与分析原图

### 确定本图范围及版本

- **新图。** 普通“修一下”执行完整框架评估；上一张的“不动身材”“只修脸”等临时限制不带入新图，新图也不继承上一张的脸、发型或服装替换。
- **同图局部返修。** 明确“只改某处”“其他不动”时，只改指定部位及允许的必要联动，沿用该图仍有效的锁定项；重新要求完整重修时重新确定范围。
- **补充重点。** “胸再大一点”“肩不够饱满”提高对应目标优先级，不自动取消当前任务的其他默认评估，也不解除既有锁定项。若新要求与锁定项直接冲突且无法判断用户是否解除限制，先简短核对。
- **批量及长期要求。** 逐张判断，仅共享用户明确指定给整组或后续照片的限制和风格；某张反馈不自动改写整组范围或 Skill 默认值。

普通修图以本次指定输入为对照，包括已修照片。返修以本图认可版本为基准；未有认可版本时使用用户指定输入，不默认采用最近一次未认可输出。版本不明且影响编辑时先核对。

### 查看实际输入与必要规则

查看照片并检查可编辑性，必要时转换受支持格式并验证，保留原图。识别身份、表情、角度、姿态、可见主要肌群及基础、服装覆盖与材质、原光源、色彩风格、景深及环境信息。锁定区域排除编辑，未入镜直接标记不适用，只深入判断可见且可能受本次编辑影响的部位。

涉及形体时读取参考文件“一、默认审美与五维判断”和“二、肌肉基础与表现收益”，再按目标选读“三、核心肌群的方向、连接与错误检查”及“四、拍摄角度与服装共同决定重点”。验收沿用所选条目的结构与错误标准，不再另读重复清单。仅修脸且不影响身体时不展开肌肉理论。环境不支持按章节读取时完整读参考文件一次并复用，不能因精简漏掉必要规则；参考缺失先查找同包文件，找不到时说明限制，不凭空替代专业判断。

观察、方案和提示词准备可合并完成，内部只记简短事实与目标，不要求逐肌群长篇分析。未看到图片或无法可靠判断的内容，不声称已经分析或完成编辑。

## 阶段 B：生成本图修图方案

### 逐部位作出处理决定

对可见主要肌群作以下判断，用户明确锁定项先于默认策略。

| 决定 | 依据与处理 |
| --- | --- |
| 需要增强 | 本图存在可改善的量感、轮廓、比例、曲面或线条，或用户明确提出增强。记录下述选定方式及可见目标 |
| 可以保留优势体积与比例 | 当前量感及比例优秀，继续明显放大收益低或易失真。保持大致体积和比例，仍可通过局部微调、曲面、衔接、自然线条及衣料呈现提升表现力；此判断不等于用户明确锁定，也不代表完全不处理 |
| 不适用或无法可靠判断 | 未入镜、遮挡、分辨率或姿态不足。不推测不可见肌肉的大小，不补画内部结构；衣料外廓和张力可在可判断范围内单独制定目标 |

根据参考规则评估基础、比例与角度，选择可组合的增强方式。

| 方式 | 使用条件及目标 |
| --- | --- |
| 体积增强 | 胸肩背臂偏薄、比例不足、训练痕迹不明显，或用户明确要求更壮时，做有方向的实际体积与外轮廓变化，依五维标准协调结果 |
| 表现力增强 | 已有肌肉基础、明显放大未必自然时，提升曲面清晰度、自然分离、轮廓利落度、肌群衔接及衣料呈现，使原有体积更容易被看见，不必显著增加总体围度 |
| 摄影与质感增强 | 体积和比例已好、形变收益低或风险高时，把更多改善分配给原光源下的曲面明暗、真实肤质与健康质感，保持自然肤色及环境；仍须服务肌肉存在感，不能仅叠滤镜 |

优秀身材优先保留优势体积与比例，通过适用的局部微调、曲面光影、自然分离、衣料和摄影表现取得小幅但可感知的改善。只有形体已接近理想、工具难以可靠实现进一步局部增强、继续形变明显更易失真，且摄影质感仍能带来真实改善这四项同时成立时，才可基本不改动形体；完全无变化不作为默认成功。明确的本图锁定项始终优先，不能借表现力优化改变用户要求不动的部位。

方案仅记录选定动作、方向、专业规则要求的联动、锁定内容及预期结果。优先用户核心诉求；必要联动不能越过锁定项，冲突时降低局部幅度或说明限制。按参考五维标准协调形体，再安排摄影处理，不用重复展开每项理论。

### 面部与整体形象

本图范围包含面部时，优先改善明显抬头纹、眉间纹、法令纹、眼周细纹、疲态及临时瑕疵；保留本人五官内部关系、表情、自然不对称、毛孔和皮肤纹理。按原光源改善眉骨、鼻梁、颧骨、面颊及下颌转折，不靠加深法令纹制造折叠度。适度整理额角、发际线稀疏、发流和蓬松度，不擅自换发型。原本状态好或细节不可辨时不强行重塑。

头肩、肩腰和腿身视觉比例按专业规则及本图短板优化，追求协调的模特感；不强制缩头或拉腿。面部优先是检查顺序，不增加独立生成轮次，也不覆盖用户的局部修改范围。

### 摄影以原片为先

依次保留原光源方向及场景氛围、改善主体立体感、协调色彩对比与肤色，最后才考虑有收益的风格化。不得新增冲突主光源、制造假高光、机械锐化或使人物与背景色温脱节。

默认沿用原片摄影风格。用户指定或确有视觉收益时，可参考徕卡的浓郁层次、哈苏的柔和中间调、富士的清透胶片层次；不按场景自动套品牌滤镜。

默认保留原片景深。用户未明确要求时，环境是重要内容的海边、旅行、建筑、街拍照，已有合理景深或人物背景距离不支持虚化时不主动模糊。仅背景明显干扰主体、损失环境信息很小且距离与透视支持时适度虚化，保留自然距离渐变、发丝与肩臂边缘。用户要求焦段观感时仅作视觉参考，不改变机位和原透视，也不声称改变真实拍摄参数。

## 阶段 C：适配工具并执行编辑

先根据实际功能、工具说明及已有结果判断能力，不按模型名称预设等级，不为分级额外生成测试图。

| 工具能力 | 执行方式 |
| --- | --- |
| A：支持局部遮罩或局部编辑 | 优先定向处理选定目标，保护锁定及已满意区域；肌群与衣料的必要联动纳入允许范围 |
| B：支持原图参考的整图编辑 | 用具体、适度保守的整图指令保护身份、动作、服装和场景，仍写清本图体积或表现力目标；不可承诺完全锁住每个像素 |
| C：仅有有限编辑能力 | 只执行可靠支持的动作；不能完成计划中的体积或表现力目标时先说明限制，不能把单纯调色包装为完成要求 |

确认实际工具可读取本次输入。提示词按以下优先级编写，将专业知识转成具体动作，删除不适用部分，不直接传入抽象模板。

1. 本次最重要的目标、输入基准和范围，用户明确增强要求置于首位。
2. 计划改变的部位、方向、幅度和可见表现；保留优势体积处仅写已选的表现力优化，不加入额外整体放大，不可判断处不补画结构。
3. 必须保留的本人身份、五官表情、动作与关节位置、骨骼连接、构图透视、背景镜面及服装款式、文字、图案、材质，连同本图锁定项。
4. 专业规则要求的肌群、比例、衣料联动及必要自然线条与光影。
5. 原光线、肤色、环境与景深保护，以及方案内有收益的摄影优化；输出单张成片，沿用画幅，不加拼图文字。

调用前与本图方案核对一次，保证核心动作未被省略，区分优势体积保留与用户严格锁定，保留指令不与选定表现力目标冲突。将理论转成具体体积、曲面、衔接、光影或衣料动作，不能将方案缩成“适度增强，保持自然”。通常一轮完成，不因部位多而拆成多次生成。

目标超出能力或已出现严重失真时，不重复相同指令。优先利用可靠局部能力、减小幅度或保留成功部分；若仍无法满足核心要求，说明实际限制，不擅自缩减用户诉求或越过修改范围。整图工具无法稳定保留衣物文字时，不反复整图重绘来碰运气；无可靠保护或局部修复路径就报告该限制。不牺牲辨识度、关节、衣物文字和背景来追求体积，不猜补无法辨认的文字。

## 阶段 D：对照目标验收、必要返修与交付

查看实际输出，与输入基准及阶段 B 方案对照，先核对身份、面部与锁定区域，再按参考规则检查形体真实性、衣物及摄影一致性。简短记为达标、缺陷、不可判断或不适用，避免重新执行已经完成的分析。

- **体积增强处：** 检查计划的体积及外轮廓变化是否真实出现，比例、线条和光影是否合理；明确增大要求不能未经说明降级为摄影处理。
- **保留优势体积及表现力增强处：** 检查大致量感和比例是否保留，同时核对计划中的曲面、衔接、自然分离、衣料呈现是否更立体、更顺眼，有无不必要的放大或漂移。
- **主要依靠摄影的完整方案：** 核对阶段 B 的适用条件，检查顺肌肉曲面的明暗、真实肤质及原片氛围是否带来可感知的健体表现力改善，不以围度增加作为条件。用户仅要求摄影处理的局部任务按其指定目标验收。
- **局部或无法判断处：** 检查锁定范围、必要联动及可评估目标，不凭生成成功认定不可核实细节已保留。

完整修图还须整体判断肌肉存在感是否提升。若只是调色、加对比或锐化，胸肩背臂表现力没有改善，判为未达标；总体围度未增加本身不是缺陷。不要求每个肌群都变化，也不能把保留比例理解成整图无须改善。

只针对真实缺陷返修。回查相关规则，明确缺失动作或错误，优先局部修复并保护已通过区域。默认首轮后最多追加一次针对性返修；达到方案目标就停止。用户明确要求继续时按新指令推进，工具拒绝的操作依工具规则处理，不改写措辞规避限制。

无可靠修复路径、返修仍失败或核心诉求无法达到时停止，保留可用版本，说明完成范围、剩余问题和工具限制，不宣布完整成功或精确肌肉增长百分比。方案达标时正常交付，不为制造变化反复放大肌肉。

交付实际成片，原图及认可版本分别保存、不覆盖；批量逐张执行、保持组内风格协调，如实报告完成数量。保存的提示词或记录须对应具体输入输出，用户只要照片时无需展示内部方案全文。
