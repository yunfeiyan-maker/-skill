# 肌肉审美与形体调整规则

适用版本 1.4.0。本文件集中提供健体审美、五维判断、肌群结构、调整方向、角度、服装及错误检查。活人感、面部与原片成像规则移至 [面部与真实摄影标准](面部与真实摄影标准.md)。处理范围、执行、验收与返修由主 `SKILL.md` 控制。只应用本图可见且允许修改的部位，不把知识表当作必须逐项放大的清单。

## 一、默认审美与五维判断

默认目标结合健身网红感、自然面部美化、肌肉表现力、真实人物质感与原图摄影氛围。胸肩背臂有明显训练痕迹，轮廓饱满、肩腰差清楚，线条比普通运动状态更明显，同时像原图中的本人状态更好、更上镜，保留阳光、健康的生活方式气质。

| 审美区间 | 判断特征 | 执行方向 |
| --- | --- | --- |
| 自然运动健体感 | 有一定肌肉基础，线条柔和，日常放松状态训练痕迹不突出 | 较低强度参照，不能仅以“自然”判定默认任务已完成 |
| 健身网红感 | 胸肩背臂饱满、立体，外轮廓和线条清楚，比例优秀，有自然分离度 | 默认目标，通过协调体积、比例、轮廓、线条和光影实现 |
| 竞技健美感 | 极端体积、极低体脂、干燥紧绷，夸张分离、密集血管、拉丝或舞台感 | 默认避免，出现过度干硬、切割感时回退 |

完整健体修图的目标是可感知的肌肉视觉表现力提升。体积、外轮廓、曲面光影、自然分离、衣料联动及摄影质感都可使肌肉更饱满、立体、有训练感，不以围度增加或极低体脂作为唯一标准；用户明确要求增加体积时，必须有实质且合理的体积/轮廓收益。原有体积优秀时可保留优势，仍可改善其呈现；工具与收益的具体取舍由主 Skill 的目标制定阶段。

五维标准用于判断专业收益和真实性，不要求每个维度或每个肌群都发生改变。

| 维度 | 需要判断和落实的内容 |
| --- | --- |
| 体积 | 肌肉的饱满度、三维厚度及厚度感是否清楚；需要增加实体体积时按位置、曲面、姿态及连接确定前向、后侧、外侧等方向，不统一等比放大 |
| 外轮廓 | 肩头外缘、侧肩厚度、胸部前向轮廓、背阔肌侧缘、胸背向腰部收束是否利落；可微调或改善边缘呈现，不直接拉宽躯干或整体缩小腰部 |
| 肌群比例 | 胸与三角肌、肩与上臂、背与腰、上臂与前臂、上半身与可见臀腿，以及头颈肩胸腰的关系；避免局部增强使邻近部位显得单薄 |
| 线条 | 胸肩分界、三角肌曲面、二头肌与三头肌轮廓、背腰过渡和原有腹肌起伏更清楚；避免深沟和比赛级切割 |
| 光影 | 沿原光源，用顺曲面的高光、中间调厚度及转折阴影表现体积；同时遵守《面部与真实摄影标准》的皮肤和成像底线，避免深色描边、过暗刻槽或锐化替代真实肌肉转折 |

## 二、肌肉基础与表现收益

以下条件服务于主 Skill 的增强方式选择，不作为人物的永久标签。

| 原片基础 | 专业判断重点 | 适合的增强方向 |
| --- | --- | --- |
| 肌肉基础较弱 | 胸肩背臂是否偏薄、外轮廓和训练痕迹不足 | 体积增强为主，协调比例，再以自然线条和光影表现新增厚度 |
| 已有一定基础 | 比例短板在哪里，哪些肌肉已有量感但曲面呈现不清 | 短板按需增厚，优势部位用表现力增强，不要求全部等比增大 |
| 基础优秀 | 已有体积及比例优势，局部衔接、曲面、自然分离和衣料是否仍有收益 | 保留总体量感，优先表现力增强；摄影与质感增强通过原光源和真实肤质服务肌肉存在感，不等于滤镜化 |

保留优势体积与比例允许局部形体微调及更好的视觉呈现，不等同严格锁定或完全不处理。明显形变的幅度由当前结构、收益和工具能力决定；基本不改形体的例外条件由主 Skill 的执行流程控制。

## 三、核心肌群的方向、连接与错误检查

下列增厚方向用于确有体积收益的部位；优势部位可采用曲面、衔接及自然光影优化，无需把每条增强动作全部执行。涉及衣物时同时应用第四节。

### 1. 三角肌，最高优先级

目标为正面宽、侧面厚、背面圆润。前、中、后束构成连续肩部结构，保持原肩关节位置，不生成三个独立肌块。肩宽已协调时可保持肩宽，通过圆润曲面、后束呈现及肩臂过渡增强表现力。

| 区域 | 增强方向 | 必须联动 | 避免 |
| --- | --- | --- | --- |
| 前束，肩部前侧 | 补足前肩偏平，增加自然前侧厚度与圆润曲面，顺接上胸和上臂 | 上胸、锁骨、上臂 | 过度前凸、胸肩生硬深沟、肩头前冲造成假性圆肩 |
| 中束，肩膀外侧 | 沿外侧增加肌肉厚度和肩头外缘圆弧，形成正面肩宽感，向上臂过渡饱满 | 肩关节、上臂、肩线与肩袖，并核对胸背比例 | 横向拉伸、独立球状肩头、肩关节外移、肩宽与胸背失衡 |
| 后束，肩膀后侧 | 侧身重点补足后肩扁平，增加后侧厚度与圆润度，使肩头有完整前后体积 | 三角肌中束、肱三头肌、上背、斜方肌和衣服后肩，形成连续曲线 | 独立后肩球、后移肱骨或关节、扭曲手臂、后束与上背断裂 |

### 2. 胸大肌，最高优先级

上胸、中下胸与下外侧共同决定整体饱满度，前向厚度在原角度下应合理；保留原胸廓和附着关系。胸部偏薄时按下表增厚，不只增强上胸；已有足够体积时保持总体量感，改善前向厚度呈现、曲面层次与胸肩衔接。

| 区域 | 增强方向与联动 | 避免 |
| --- | --- | --- |
| 上胸，锁骨部 | 增加锁骨下方自然饱满度和前向厚度，改善偏平及胸肩衔接，与前束自然连接；检查锁骨、前束、腋下和前胸衣料 | 锁骨下突然鼓起、胸肩生硬分界、整个胸肌异常上移 |
| 中下胸，胸肋部 | 增加整体前向厚度及中下胸饱满度，下缘与下外侧有柔和体积转折；保留胸外侧、胸廓、腋下连接并联动胸部衣料 | 过度鼓起或下垂、深黑下缘、僵硬方块胸、刻画过深中缝 |

胸部光影顺原受光方向，高光和中间调体现前向厚度，适当光线下用柔和阴影表现下缘，保留自然皮下脂肪覆盖。

穿衣时同步检查前胸撑起、外侧面料张力、腋下连接及周围接缝、褶皱、垂坠。衣料轮廓随体积改变，但不把服装款式、开口或接缝结构重新设计。

### 3. 背阔肌，高优先级

自然展开背部两侧，改善腋下后方至腰部的侧缘，宽度与肩膀协调；背面和半侧面兼顾厚度，保留向腰部收束的曲线。正面与抬臂照也检查实际可见的侧缘。

联动肩部、腋下、上臂、肩胛区域、腰腹、侧腰和背部衣料。避免拉宽整个躯干、直线三角形侧缘、极端缩腰、肩胛连接异常；被遮挡区域不补画肌肉边界。

### 4. 手臂，高优先级

目标为正面有量感、侧面有厚度，放松时仍有训练痕迹。偏薄时不能以描线代替厚度，也不能只放大二头肌；已有量感时可保持围度，优化二头、三头与前臂的自然关系、转折和光影。

| 区域 | 增强方向及动作条件 | 必须联动及检查 |
| --- | --- | --- |
| 肱二头肌，上臂前侧 | 增加前侧饱满度，形态服从手臂旋转和动作；放松时保留柔和弧线，发力时适度加强肌峰及线条 | 肱肌、肘部、前臂；避免所有姿态都生成夸张肌峰或肌肉形态与动作不符 |
| 肱三头肌，上臂后侧 | 增加后侧及外侧饱满度，侧面增强真实厚度，线条服从动作 | 三角肌后束、肘部、衣袖；侧身尤其检查后束至三头肌的连续厚度 |
| 前臂 | 与上臂保持合理体积关系，顺动作及光线改善轮廓 | 肘部、手腕和腕部自然收束；不增加夸张青筋 |

上臂的体积和曲面变化均应与肘关节、前臂、手腕的比例及位置协调。

### 5. 腰腹，中高优先级

服务于肩腰差与整体利落感，不追求极端腹肌分离。

- 腹直肌沿已有肌块优化起伏、厚度与自然线条，保留腹部厚度、肚脐形态和轻微不对称。原图没有线条、无法判断或被遮挡时，只优化紧实感和轻微自然光影，不生成深刻六块或八块腹肌。
- 腹外斜肌改善侧腰紧实和胸廓向腰部收束，保留躯干旋转关系；人鱼线只在对应区域可见时轻微优化。
- 前锯肌仅在原图可见且光线允许时加强自然层次，不强制生成锯齿状肌肉。
- 联动胸廓、腹斜肌、骨盆和衣物；避免深沟、极端细腰、脱水皮肤及胸廓—腰—骨盆失衡。

### 6. 斜方肌与上背，辅助优先级

保留颈部至肩部的自然曲线，按可见范围改善上背厚度；背面检查肩胛周围层次，协调后三角肌和背阔肌。避免耸起斜方肌、挤短颈部、僵硬肩颈或不真实肌肉堆叠，不抢走三角肌的主导地位。

### 7. 臀腿与下肢，按构图决定

全身照片检查上下身协调。可见且需要改善时，臀肌保持自然饱满及骨盆关系，股四头肌改善大腿正面厚度，腘绳肌保留后侧体积，小腿保持自然轮廓。适度改善腿身比与修长感，不强拉腿长。

联动骨盆、膝盖、脚踝、站姿重心，不改变膝踝及脚的位置、脚部接地或身体重心。被衣服遮挡时按真实衣料廓形呈现，不画出遮挡下的肌肉分界。

### 8. 整体视觉比例

头颈肩胸腰及上下身保持协调的模特感。肩部圆润与自然舒展优先于缩头；必要时轻调头部整体相对大小，保留五官内部关系、发流、颈肩连接和透视，避免骤缩头部。锁骨与上胸自然衔接，不刻出突兀凸骨。比例本已优秀时保留，不为满足固定头肩比或腿长指标而改变形体。

## 四、拍摄角度与服装共同决定重点

| 角度或穿着 | 主要肌群及必须检查的结果 |
| --- | --- |
| 正面 | 上胸、三角肌中束、肱二头肌与腰腹；检查肩腰差和胸肩连接，兼顾可见背阔肌侧缘 |
| 45 度半侧面 | 上胸、三角肌整体、肱三头肌与背阔肌侧缘；检查胸部前向厚度、肩头圆润度及手臂厚度 |
| 90 度侧面 | 后三角肌、胸部与肱三头肌；检查前后肩厚度及视觉圆肩 |
| 背面 | 背阔肌、后三角肌与上背；检查肩胛关系和自然倒三角 |
| 正面紧身衣 | 胸、肩、手臂；检查前胸撑衣和肩袖张力 |
| 侧面紧身衣 | 上胸、后束与肱三头肌；检查衣料前后厚度和自然褶皱 |

角度与穿着条件可叠加，表示观察重点；是否需要修改由本图状态与用户范围决定。

侧身依次检查后束是否偏平、肩部前后厚度、上胸前向厚度、三头肌体积、颈部至斜方肌和肩头的衔接，以及姿态带来的圆肩、含胸或前移视觉。允许在原动作下改善视觉体态，不据单张照片诊断真实关节异常，不扭转肱骨或移动关节。

| 服装类型 | 体积如何体现 |
| --- | --- |
| 赤膊 | 直接呈现可见体积、胸肩背臂外轮廓、自然分界及腰腹紧实感，用真实明暗增强厚度，保留皮肤纹理和适度皮下脂肪 |
| 紧身运动服 | 上胸撑起前胸，三角肌撑起肩线及肩袖，上臂有包裹感，腰腹利落；接缝、褶皱、纹理与面料受力同步，不凭空显露腹肌 |
| 背心、无袖上衣 | 重点呈现三角肌圆润度、三头肌侧面厚度、胸部与腋下连接及肩臂自然线条 |
| 宽松衣物 | 通过肩宽、胸廓、挺拔程度与自然衣物廓形体现体积，保留垂坠和受力，不强制显露遮挡的肌肉分界 |

服装由肌肉自然撑起，不在面料表面绘制肌肉。身体与衣料联动不授权改变款式、Logo、文字或材质。
