# 运动男子健体修图 Skill

让健身照、穿搭照和日常照更有状态，保留本人辨识度与自然摄影感。

这是一个提供修图规则的 Agent Skill，当前为 **V0.11 轻量执行稿，暂不定稿**。实际修图需要宿主助手提供图像编辑工具；本仓库不包含模型、API 密钥或图像编辑额度。

## 能做什么

- 中度增强胸肩背臂的饱满感，协调肩腰比例和体态。
- 适度整理面部轮廓、发际线、疲态与临时瑕疵，保留本人特征和自然肤质。
- 改善衣料贴合与多余褶皱，保留服装材质、接缝和文字。
- 根据原图选择浓郁鲜艳、柔和通透或自然胶片的调色方向。

当前默认采用中度自然健体增强。可以要求降低强度，或只修改指定部位。体脂与身高相关表述仅描述视觉目标，不能据照片测量实际数值。徕卡、哈苏与富士仅为审美参考，与品牌无关联。

## 安装到本地 Codex

1. 下载本仓库，找到 `skills/athletic-male-photo-retouch/` 文件夹。
2. 将该文件夹完整复制到当前项目的 `.agents/skills/`，或个人目录 `~/.agents/skills/`。选择一处即可，保留已有同名版本。
3. 确认最终文件路径如下。若 Skill 没有出现，检查文件扩展名与嵌套层级，必要时重启 Codex。

```text
.agents/
└── skills/
    └── athletic-male-photo-retouch/
        └── SKILL.md
```

上传照片后，在消息中明确写出 Skill 名称。在支持 `$` 选择技能的界面中，也可以使用 `$athletic-male-photo-retouch`。

> 使用 athletic-male-photo-retouch 修我上传的这张照片。中度自然增强，保留本人特征，调色偏浓郁鲜艳。请直接调用当前可用的图像编辑工具，输出一张独立成片；如果工具不可用，请说明缺口。

Skill 被识别后，仍需确认当前环境能够编辑图片。其他助手的安装目录与工具适配尚未逐个平台测试。

## 先用 Prompt 试一张

如果使用的工具支持上传原图并编辑图片，可以直接复制 [完整 Prompt](docs/prompts.md)，无需安装 Skill。

已认可成片需要微调时，指定保留项与修改部位，例如：

> 保留这版的脸、颜色、服装和构图，只把侧面肩部后束修得饱满一点，保持原动作与关节位置，其他区域尽量不变。

## 使用边界

生成式修图可能改变面部细节、服装小字、镜像或背景。出图后逐张检查本人辨识度、人体结构、肤质、服装文字和背景直线；发现错误时基于已认可版本做局部修复。不要将安装成功等同于修图成功。

仓库仅包含文字规则与说明，不包含私人照片、聊天记录或账户信息。当前未附开源许可证，公开可见不等同于授予任意复制、修改或商用的许可。

安装目录与识别方式参考 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。
