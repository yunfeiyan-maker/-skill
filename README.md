**Lean Muscle Photo Glow-Up**

让健身照、穿搭照和日常照更有健身博主感，保留本人辨识度与真实摄影质感。

## 默认目标

默认目标为**健身网红感、面部自然美化、肌肉表现力增强、真实人物质感与原图摄影氛围**。首次分析和编辑方案就同时考虑形体、面部、真实皮肤与摄影保护，以首轮得到可直接用于社媒的自然照片为目标，避免比赛式干硬、脱水与极端分离。

- 体积不足或用户明确要求更壮时，实施有方向的体积与外轮廓增强。
- 已有较好基础时，可保留优势体积和比例，通过局部微调、曲面光影、自然分离和衣料联动提升表现力。
- 形体接近理想、工具进一步形变不可靠且失真风险更高时，可依规则将重点分配给有实际收益的摄影与质感优化。
- 保留优势体积不等于完全不处理；围度增加也不是所有照片的成功条件。完整修图须有可感知的健体表现力改善，单纯滤镜、对比度或锐化不足以交差。

首次编辑默认主动改善明显抬头纹、法令纹、眉间纹、眼周疲态与局部瑕疵，保留本人骨相、眼神、嘴角、微表情、面部张力及自然不对称。去皱仍保留合理毛孔、细微纹理和色差；皮肤自然哑光至场景支持的真实反光，避免假油光、蜡感、塑料磨皮及抹油海报效果。原片确有汗珠、水滴或局部反射时按场景保留，不扩张为全身油亮。

腹肌沿原有结构处理，衣料随体积合理联动，保留材质、接缝、Logo 和文字。摄影默认保留光源、色温、曝光特点、自然锐度差异、景深与轻微颗粒；人物、服装和背景成像一致，不强制加噪点、套品牌滤镜或模糊环境。

## 执行方式

主入口采用五个必须完成的检查点：确定输入与编辑范围 → 看图后确定具体目标 → 生成完整指令并执行编辑 → 对照输入验收 → 必要返修并交付。快速模式可隐藏内部判断，但不省略检查点。

专业规则分为两份参考：面部与真实摄影标准集中管理身份、神态、皮肤、自然美化和原片成像；肌肉审美与形体调整规则集中管理五维判断、肌群方向、比例及衣物联动，按本图需要读取并复用。

互动模式支持按用户需要简短沟通与反馈；快速模式在输入明确时直接出片。两种模式共用首次真实感要求，首次工具指令必须带入具体形体动作、自然面部美化、皮肤约束及原片摄影保护。验收用于核实质量，不采用先夸张增强再靠返修恢复真实感的方式。

每张新图重新确定范围，不继承上一张“只修脸”“身材不动”等临时限制。同图返修沿用认可版本及仍有效的锁定项；用户仅强调某个肌群，不会自动取消其他默认评估。

支持局部编辑时优先保护满意区域；只能整图编辑时更重视身份、服装和场景稳定性。能力不足或核心要求未实现时如实说明，默认首轮后最多追加一次针对性返修，不无限生成。
