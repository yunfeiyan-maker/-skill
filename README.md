# 运动男子健体修图 Skill

让健身照、穿搭照和日常照更有健身博主感，保留本人辨识度与真实摄影质感。

当前版本为 **1.3.0**。这是提供修图规则的 Agent Skill，实际编辑需要宿主助手提供图像工具；仓库不包含模型、API 密钥或编辑额度。规则已通过静态检查，实际成片质量及不同工具的稳定性仍需逐张实测。

## 默认目标

在原有身体基础上提升可感知的**肌肉表现力**。胸肩背臂更有量感、立体感和训练痕迹，肩腰比例协调，保留健康日常人像气质，避免比赛式干硬、脱水与极端分离。

- 体积不足或用户明确要求更壮时，实施有方向的体积与外轮廓增强。
- 已有较好基础时，可保留优势体积和比例，通过局部微调、曲面光影、自然分离和衣料联动提升表现力。
- 形体接近理想、工具进一步形变不可靠且失真风险更高时，可依规则将重点分配给有实际收益的摄影与质感优化。
- 保留优势体积不等于完全不处理；围度增加也不是所有照片的成功条件。完整修图须有可感知的健体表现力改善，单纯滤镜、对比度或锐化不足以交差。

面部仍优先保留本人五官与表情，改善明显纹路、疲态、发际线及自然立体感。腹肌沿原有结构处理，衣料随身体体积和呈现合理联动，保留材质、接缝、Logo 和文字。摄影默认保留原片光线、风格及景深，不自动套品牌滤镜或模糊环境。

## 执行方式

主入口负责四阶段控制：识别任务与原图分析、制定方案、适配工具执行、对照验收与必要返修。专业参考文件集中定义五维判断、肌群方向、比例联动、角度、服装与结构错误，按本图需要读取。

每张新图重新确定范围，不继承上一张“只修脸”“身材不动”等临时限制。同图返修沿用认可版本及仍有效的锁定项；用户仅强调某个肌群，不会自动取消其他默认评估。

支持局部编辑时优先保护满意区域；只能整图编辑时更重视身份、服装和场景稳定性。能力不足或核心要求未实现时如实说明，默认首轮后最多追加一次针对性返修，不无限生成。

## 安装到本地 Codex

1. 下载仓库，找到 `skills/athletic-male-photo-retouch/`。
2. 将该文件夹**完整复制**到当前项目的 `.agents/skills/`，或个人目录 `~/.agents/skills/`。选择一处即可，保留已有同名版本。
3. 保留以下层级，不能只复制入口文件。若 Skill 未出现，检查扩展名与嵌套层级，必要时重启 Codex。

```text
.agents/
└── skills/
    └── athletic-male-photo-retouch/
        ├── SKILL.md
        └── 运动男子健体修图参考/
            └── 肌肉审美与形体调整规则.md
```

上传照片后明确写出 Skill 名称；支持技能选择的界面中也可使用 `$athletic-male-photo-retouch`。

> 使用运动男子健体修图 Skill 1.3.0 修这张照片。按原片基础和工具能力提升肌肉表现力：需要增厚的部位落实可见体积变化，优势部位保留大致体积与比例并改善曲面、衔接和衣料呈现。保留本人、动作、服装与原片光线和景深，直接调用可用工具出片，按本图目标验收；工具无法完成时说明限制。

Skill 被识别不代表当前环境具有图像编辑能力。其他助手的安装目录与工具适配尚未逐个平台验证。
