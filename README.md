# 运动男子健体修图 Skill

让健身照、穿搭照和日常照更有状态，保留本人辨识度与自然摄影感。

这是一个提供修图规则的 Agent Skill，当前版本为 **1.2.1**。普通修图默认按完整框架排查，以身材比例和健体表现的可见提升为核心。「先面部，再全身，最后摄影氛围」是处理与验收顺序，面部完成后仍继续执行适用的身体优化。实际修图需要宿主助手提供图像编辑工具；本仓库不包含模型、API 密钥或图像编辑额度。

## 能做什么

- 优先去除明显法令纹、抬头纹等面部纹路，增加自然折叠度、优化发际线，保留本人五官与表情。
- 协调模特感小头宽肩比例、锁骨与肩部饱满度，提升上胸饱满度、中胸厚度、下胸及下外侧体积，以及二头肌、三头肌维度与细节。
- 同时增加可见背阔肌的宽度、厚度与倒三角感，收紧并修长腰线；腹肌原本有线条才增加厚度和分离度，没有则只稍加光影。
- 对穿衣部位同步提升真实撑衣感、包裹感和衣料张力，保留服装材质、接缝、Logo 和文字。
- 根据场景匹配调色与自然人像镜头观感，主体清晰、背景轻微虚化。

当前以本次输入为对照，默认目标为约 **30% 的综合视觉维度提升**，体现在肌肉体积、厚度、饱满度与整体比例上。这不是每个部位宽度机械增加 30%，也不是测得真实肌肉量变化。身材基础好或已经修过的照片同样按整套框架检查和优化，不能自行改为只修肤色或光影。

可以明确要求降低强度，或只修改指定部位。只有用户说「只改某处」「其他不要动」或指定锁定区域时，编辑范围才收缩为局部。体脂与身高相关表述仅描述视觉目标；徕卡、哈苏与富士仅为审美参考，与品牌无关联。

## 安装到本地 Codex

1. 下载本仓库，找到 `skills/athletic-male-photo-retouch/` 文件夹。
2. 将该文件夹完整复制到当前项目的 `.agents/skills/`，或个人目录 `~/.agents/skills/`。选择一处即可，保留已有同名版本。
3. 确认最终文件路径如下。若 Skill 没有出现，检查文件扩展名与嵌套层级，必要时重启 Codex。

```text
.agents/
└── skills/
    └── athletic-male-photo-retouch/
        └── SKILL.md
```

上传照片后，在消息中明确写出 Skill 名称。在支持 `$` 选择技能的界面中，也可以使用 `$athletic-male-photo-retouch`。

> 使用运动男子健体修图 Skill 1.2.1 修我上传的这张照片。按完整框架排查，以当前图片为对照，落实约 30% 的综合视觉增强目标。先处理面部，再提升头肩比例、胸肩背臂和腰腹的适用部位；穿衣部位同步提升撑衣感，主体清晰、背景轻微虚化。请保留本人五官、表情及姿势，直接调用当前可用的图像编辑工具输出独立成片，并对照输入检查身材是否实际提升；如果工具不可用，请说明缺口。

Skill 被识别后，仍需确认当前环境能够编辑图片。其他助手的安装目录与工具适配尚未逐个平台测试。

## 先用 Prompt 试一张

如果使用的工具支持上传原图并编辑图片，可以直接复制 [完整 Prompt](docs/prompts.md)，无需安装 Skill。

已认可成片需要微调时，指定保留项与修改部位，例如：

> 保留这版的脸、颜色、服装和构图，只把侧面肩部后束修得饱满一点，保持原动作与关节位置，其他区域尽量不变。

## 使用边界

生成式修图可能改变面部细节、服装小字、镜像或背景。出图后逐张检查本人辨识度、人体结构、肤质、服装文字和背景直线；发现错误时基于已认可版本做局部修复。不要将安装成功等同于修图成功。

仓库仅包含文字规则与说明，不包含私人照片、聊天记录或账户信息。当前未附开源许可证，公开可见不等同于授予任意复制、修改或商用的许可。

安装目录与识别方式参考 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。
