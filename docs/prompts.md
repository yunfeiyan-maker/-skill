# 直接输入的修图 Prompt

在支持原图编辑的 AI 工具中上传照片，再复制对应文案。以下为修图目标，尚未补充这些 Prompt 的实际运行对比图。

## 通用版 · 自然健体与浓郁调色

请直接编辑我上传的这张照片，做自然的运动男子健体修图，输出一张独立成片。

保留本人辨识度、五官特征、原始表情、发型、姿势、场景、构图和摄影透视。保留毛孔、真实皮肤纹理和自然不对称。

在原图基础上中度增强实际可见的胸、肩、背和手臂，让肌肉饱满、连接自然，保留适度皮下脂肪。适度优化肩腰比例和挺拔感，不夸张扩肩或拉长腿，不凭空制造腹肌。侧身照兼顾三角肌后束与肩背衔接，保持原动作和关节位置。

穿衣照片让胸肩臂自然撑起衣服，整理影响观感的多余褶皱，保留面料厚度、接缝、款式、Logo和文字。被衣服遮住的肌肉不要画到布料表面。

面部适度改善疲态、临时瑕疵与光影，轻微整理轮廓和发际线，保留本人特征与自然发流，避免过度磨皮。

调色偏浓郁鲜艳的徕卡审美，保留暗部层次，肤色健康自然，不偏橙红。根据原图光线调整，保持光源方向一致。

出图前检查五官、头颈肩连接、手指、镜中反射、背景直线与服装字样。如当前工具只能分析图片、不能编辑原图，请直接说明。

## 柔和版 · 生活人像与通透氛围

请直接编辑我上传的照片，保留本人五官、表情、皮肤纹理和原始场景。胸肩臂自然饱满一些，比例挺拔协调，保持真实人体结构和衣料受力关系。淡化临时瑕疵与疲态，脸仍然像本人。整体采用柔和、通透、克制的哈苏人像审美，保留中间调和细腻光影，不改变原图光源方向。输出一张独立成片。

## 局部修复版 · 衣服字样

同时上传已认可成片与对应原图，标明编辑目标和细节参考。

以我上传的已认可成片为编辑目标，对应原图为还原依据。保留这版的脸、身材、构图和调色，只修复胸前被改错的服装字样及其必要关联区域。文字、位置、针织纹理和接缝参照原图；如不清楚，请先告诉我需要哪一处近照。输出一张独立成片。
