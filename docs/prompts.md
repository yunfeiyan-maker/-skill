# 直接输入的修图 Prompt · 1.2.1

在支持原图编辑的 AI 工具中上传照片，再复制下面的通用提示词。默认按完整框架排查，先面部、再全身、最后摄影氛围是关注与验收的先后顺序，可以合并为一次编辑；不要求分步骤反复生成。只编辑实际可见或能由衣料廓形合理呈现的部位。

以下描述修图目标；生成式编辑可能重绘细节，不能把规则或提示词的完整程度等同于成片质量。

## 通用提示词

请直接编辑我上传的照片，按完整的运动男子健体修图框架，输出一张独立成片。保留同一个人的身份、原始表情、动作、构图、摄影透视和场景，同时落实可见的身材比例与肌肉维度提升。

先排查面部、头肩、肩与锁骨、胸、手臂、腹肌、背、腰线、服装联动及摄影氛围，再执行各适用部位的优化。以本次指定输入为对照，目标为约 30% 的综合视觉维度增强，实际提升肌肉体积、厚度和饱满度，各部位协调。不要将每个部位的线性宽度机械拉大 30%，也不要声称测得真实肌肉量变化。原本身材好、已经修过或用户只强调某个问题，都不能作为省略其余适用模块的理由。保留身份、姿势和真实骨骼结构，同时允许自然地增强肌肉大小；不能只增加锐化、对比度或调色。

首先处理面部。保留本人眼鼻嘴的个人特征、五官内部比例和自然不对称，局部去除明显法令纹、抬头纹、眉间纹和眼周细纹，淡化疲态与临时瑕疵，保留毛孔和细腻皮肤纹理。根据原有光源，适度加强眉骨、鼻梁、颧骨、面颊转折及下颌的明暗层次，增加自然面部折叠度。整理额角与发际线，改善稀疏或不整齐处，保留原发型、自然发流和细碎发。保持原有神态，避免整脸磨平、过度美颜和改变本人五官。

再调整头肩和身体比例。营造协调的小头宽肩模特感，适度增加肩宽及三角肌前、中、后束的饱满度；必要时轻微调整整体头部的视觉比例，保持五官比例和颈肩连接自然。加强锁骨轮廓、锁骨窝与上胸之间的光影衔接，保留真实骨骼结构和关节位置。

细化胸部和手臂。上胸增加饱满度与自然线条，中胸增加向前的厚度，下胸及下外侧增加饱满体积、自然下缘和侧向延展，使胸部从上至下有立体支撑，整体胸肩连接顺畅。与输入相比，应能看出肌肉体积和厚度的变化。手臂适度增粗，增强二头肌、三头肌的体积及自然沟壑，分界符合姿态、发力与光线，避免过深肌肉分离和夸张青筋。

腹肌按原片判断：原本有可辨认线条时，才适度增加肌块厚度、体积与分离度；原本没有线条时，只稍微增加自然光影和紧实感，不凭空画出成排肌块、明显中线或深沟。遮挡导致无法判断时，不假定原本有腹肌线条。

协调背部和腰部。同时增加可见背阔肌的宽度与厚度，增强腋下至侧腰的肌肉支撑、后侧饱满感及上背立体感，与肩腰形成更清楚的自然倒三角。正面、抬臂照也检查可见背阔肌侧缘，按姿态处理，不改变肩关节或挤压腋下。减少腰侧和下腹赘肉感，让腰部更细、腰线更修长；相关部位实际可见时，轻微呈现自然人鱼线感，保留合理皮下脂肪与骨盆结构。

同步处理服装。衣服包裹的胸、肩、背和手臂增强后，必须同步提升对应部位的撑起、包裹和饱满度，调整必要的张力、贴合及褶皱。保留服装款式、材质、颜色、接缝、文字和 Logo。肌肉线条的显现服从面料厚度、松紧与遮挡，不把腹肌或人鱼线画在衣服表面。

最后处理摄影质感。保留原光源方向与自然肤色，按场景选择合适调色。模拟自然人像镜头的景深观感，人物清晰、背景轻微柔化，保留场景辨识度、背景几何与干净的发丝和肩部边缘。近景可参考 50–85mm 人像质感，需要交代环境的全身照可参考 35–50mm；这些只描述视觉方向，不改变原始机位、构图或人物透视。

出图后对照本次输入，先核对脸部辨识度、纹路、折叠度与发际线，再检查头肩比例、胸部饱满度和下胸体积、背阔肌宽厚、肩臂体积、腰腹及服装联动是否实际提升，同时核对肌肉连接、服装小字、镜像、背景直线和虚化边缘。只改善肤色、光影或清晰度而未体现身材提升，不能算完成整套健体修图。约 30% 是目标，不凭生成成功宣称精确达到。未入镜、被遮挡或本次明确局部修改未涉及的部位不强行补画。工具无法编辑或未完成的部分请如实说明。

## 指定调色时追加

按原图选择一种适用方向即可，不必同时叠加。

- 浓郁鲜艳：偏徕卡审美，色彩有厚度、暗部有细节，肤色自然，不偏橙红。
- 柔和通透：偏哈苏审美，中间调丰富，高光与阴影过渡细腻，保持自然肤色。
- 自然胶片：偏富士胶片审美，高光柔和、阴影有层次，可有轻微自然颗粒，保留随拍感。

以上为审美参考，与品牌无关联，不要求精确模拟相机色彩科学。

只有用户明确要求「只改某处」「其他不要动」或指定锁定区域时，才使用局部返修提示词。一般修图或仅强调某个不足，仍按完整框架排查。

以我上传的当前认可版本为编辑目标。保留这版的脸、头肩胸臂、服装款式、调色、景深和构图，只适度减少腰侧及下腹赘肉感，协调腰线与必要的衣料贴合，不额外增加腹肌或改变其他区域。保存为新版本。

## 局部返修：仅修面部

以我上传的当前认可版本为编辑目标。保留这版的身体、服装、姿势、调色、景深和背景，只去除明显面部纹路，适度增加自然面部折叠度并整理发际线，保留本人五官与表情、毛孔和真实肤质。保存为新版本。
